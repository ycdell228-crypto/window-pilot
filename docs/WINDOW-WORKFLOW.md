新增3个MCP入口：

1. begin_window_session：提供hwnd、明确access和purpose，内部刷新窗口枚举、绑定、获取60秒控制租约、返回统一截图与控件。仅接受后台权限；purpose不是授权凭证。
2. act_and_observe：提供session_id、返回的state_id、tool（click或control_action）和action_args。内部续租、补充观察凭据、调用原有输入入口、重新观察。模型仍提供控件ID或截图坐标；state_id防止旧状态坐标误用。禁止覆盖内部凭据，不自动重新获取过期租约，不换路线重试。
3. end_window_session：释放自己持有的控制权并解绑；重复结束幂等，不关闭用户应用。连接dispose沿用Coordinator断开与未知故障保留，清空该连接的工作流/观察/绑定缓存。

原低层工具全部保留。统一状态中仍提供target_id供诊断；返回effect_verified:false，动作结果与新观察状态分别表示。输入异常、结果未知或后续观察失败锁定该工作流输入；只读诊断不自动解锁。开始观察失败清理绑定；部分观察返回但阻止后续输入。截图在MCP顶层图片位置返回，不扩大为桌面截图。
