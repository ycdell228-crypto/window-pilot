# 后台点击、滚动复核与拖拽边界

日期：2026-11-09。隔离分支 `feat/background-observation`，基于 `5cdb8d8`；交验后用户回复“继续”，接受本小项并授权本地存档。未发布或部署。

## 能力和接口

- 现有左键单击、右键、左键双击、横向和纵向滚动走 `PostMessageW`，不移动真实鼠标，不使用全局输入，不自动切换前台兜底。
- `observe` 截图结果新增 `background_mouse_actions`，统一窗口状态的截图信息沿用该字段。上述动作标为 `unverified`：自有测试窗口通过不代表任意目标应用已验证。
- `click` 接受独立的 `action: "drag"` 与起点 `x/y`、终点 `end_x/end_y`。后台拖拽尚无经过验证的后端；参数合法时在派发前返回 `BACKGROUND_DRAG_BACKEND_UNAVAILABLE`，`attempt_input: not_sent`。不捕获鼠标，不调用前台拖拽。
- 拖拽坐标须为客户区范围内的整数，不可混用滚动参数；非拖拽动作不可传终点。权限、窗口绑定、共享停止和单次观察规则继续适用。拒绝后需重新观察，不因确定未发送的拒绝锁定未知故障。
- 双击不支持时不改成两次单击；输入部分执行或结果不明时保留证据并停止，不重复发送。

## 已完成验证

- 普通检查：55 通过、0 失败，17 个跳过入口；见 `.local/background-mouse-tests.txt`。
- 鼠标专项：8 通过、0 失败（1 个契约测试、7 个原生测试）；见 `.local/background-mouse-native.txt`。
- 自有原生窗口实际接收左键、右键、双击和四种滚动方向；独立读取接收端计数，并核对截图中视口标记变化。覆盖负屏幕坐标的子窗口路由、双击权限/窗口类别拒绝、部分执行和派发屏障失败。
- 七次正常动作前后采样均未发现前台窗口或真实光标变化，目标在前后采样均非前台。证据在 `.local/background-mouse/mouse-effects.json` 与同目录截图。
- 拖拽拒绝时接收端计数不变、消息为空、观察凭据已消费；契约测试禁止调用 PostMessageW、SendInput、SetCursorPos、SetCapture 或前台动作。
- `git diff --check` 通过；生产目录基线 90 个文件哈希一致。媒体及运行证据不进入 Git。

## 验收边界与后续

本项验证仅覆盖自有测试窗口，不构成实际应用普遍兼容性或连续无干扰证明；检查到派发之间仍存在竞态，应用也可能自行激活。

本项交验的是现有点击/滚动效果复核、能力提示及明确的拖拽拒绝，不是已实现后台拖拽。后台按键同样仍为明确拒绝；整值替换及实际应用兼容性仍需后续核查，第2项整体尚未完成。用户验收本小项后才本地存档；整体输入项验收完成后再按 WP-NEXT-026 开发布与插件更新对话。
